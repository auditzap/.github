# AuditZap

AuditZap is a website audit tool. It runs 40 checks across Critical, Performance, SEO, Quick Wins and AI Visibility, and shows you what to fix first. It is free to start at [auditzap.io](https://auditzap.io).

## API

The REST API is part of the Agency plan. Start audits, poll them, and download the results as CSV, plain text or PDF from your own tools. Read the [API docs](https://auditzap.io/docs/api).

## Our crawler

Audits crawl with the user agent `AuditZapBot`. The free tools use `AuditZapToolBot`. Audits follow robots.txt rules addressed to AuditZapBot by name. For our IP addresses and how to allow or block the crawler, see [auditzap.io/bot](https://auditzap.io/bot).
